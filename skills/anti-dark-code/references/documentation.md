# Explanation depth

Load for first setup or when the person sets or changes how much explanation they want. The [core](../SKILL.md) controls authority and evidence; this adds no installation, cleanup or publication permission.

At setup or first documentation use, offer: "How much explanation would help: plain language, balanced, or developer shorthand?" These select `guided`, `standard`, or `expert`. Experience suggests a default; the person's choice controls. Continue independent work while the choice is pending, using concise standard explanations.

Keep one recorded choice. Reuse Scaffold-Kit's Triage Card Explanation depth (or Interview depth) in ARCHITECTURE.md when present. Otherwise save authorized changes in the existing repo-owned calibration README, never explanatory prose. If absent, use the existing task record; one-off work can keep it in conversation. Do not create a global profile, settings file or second setting.
