# Anti-Dark-Code Calibration

This directory is repo-owned memory. The shared skill updater preserves it.

Read only the files relevant to the current pass. Update them when evidence changes. Each human-authored claim should carry a confidence label and evidence path.

Files:

- `repo-profile.json` - deterministic inventory and risk indicators
- `invariants.md` - load-bearing truths and approval boundaries
- `system-map.md` - accumulated runtime, ownership, trust, and rule-authority map
- `gates.json` - exact reviewed command arrays and machine cautions
- `verification-plan.json` - status of all 20 capabilities
- `coverage-ledger.md` - audited surfaces and freshness
- `findings-ledger.md` - open, fixed, refuted, deferred, and approval-gated findings
- `upstream-candidates.md` - repo-agnostic lessons proposed for flow-back
- `upstream.json` - source version and promotion policy

Do not store secrets, raw personal data, or machine-specific absolute paths here.
