# Writing hygiene

Compatibility reference `06`. Load for the final check of prose touched in the active task. The [core](../SKILL.md) controls scope, evidence, privacy and authority. This reference produces no separate pass or repository-wide rewrite.

## Preserve meaning

Keep facts, uncertainty, scope limits, intentional local voice and host-specific presentation differences. New technical claims need source evidence. Honor caller-supplied banned terms. For newly authored workflow prose, use ASCII punctuation and straight quotes; preserve exact quotations, code, data, localized text and authored content.

A prose request cannot change legal/product commitments, persisted text, identifiers, schema keys, pragmas, toolchain directives or other interpreted text. Follow [Document](tasks/document.md) for that classification and [language boundaries](12-transcreation-boundary.md) when present.

## Edit by subtraction

Name the subject, risk and safeguard directly. Prefer plain words and short sentences. Cut syntax narration, repeated conclusions, generic summaries, unsupported certainty, stock openings/wrap-ups, corporate or marketing filler, apology padding, mirror-contrast slogans and forced repeated cadence. Keep actual legal wording intact.

Keep comments explaining intent, invariants, trusted inputs, ordering, idempotency, privacy, state, language boundaries and consequences of moving code. Remove or correct comments that repeat code or contradict evidence.

## Artifact-specific checks

Commit messages, when commits are authorized, name the area and actual change. PR notes name what changed, why, verification, remaining uncertainty, risk and pending approval. Neither can imply broad coverage from a narrow edit. Unknowns retain the existing record shape and the core's confidence meanings.

Read changed text once for facts and once for unnecessary phrasing. Check punctuation only where the newly authored prose rule applies. Return changed paths or proposed text, caller lint rules applied, and lines preserved because changing them would alter meaning. Do not manufacture certainty to improve tone.
