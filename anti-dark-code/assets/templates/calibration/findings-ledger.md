# Anti-Dark-Code Findings Ledger

Keep settled work settled unless new evidence appears.

For product findings add a linked contract/acceptance criterion and classification:
defect, justified improvement, hypothesis or preference. Keep severity, confidence
and existing status meanings separate. Record counterevidence and preserved
strengths; a technical defect is not the only kind of supported finding.
